# 熊本DB設計セミナー資料

「AI時代『真面目に』アプリ開発フローを学ぶ 〜DB設計編〜」の資料一式。

AIを使えば画面や機能はすぐ動かせるが、その過程で**業務の意味・データの構造・守るべきルール**を確認する工程が抜けやすい。このセミナーでは、データの意味と業務ルールを決める仕事は結局残る、という前提のもと、参加者がAIと一緒にデータモデリングを進められることを目指す。

## 構成

| ファイル | 内容 |
|---|---|
| `docs/DB設計セミナー_議論まとめ.md` | 企画の背景・対象者・題材選定などの議論まとめ |
| `docs/DB設計セミナー_スライド.md` | スライド原稿（Marp形式） |
| `docs/DB設計セミナー_スライド.pdf` | スライドの書き出し版 |
| `docs/AI時代のアプリ開発_DB設計編.pptx` | スライドのPowerPoint版 |
| `docs/備品貸出管理アプリ_データモデリング.md` | セミナーの題材「備品貸出管理アプリ」の概念・論理・物理データモデル（ER図・PostgreSQL DDL） |
| `docs/備品貸出管理アプリ_データモデル図.html` | 上記モデルをER図でまとめたページ。ブラウザで直接開いて閲覧する |

## 題材：備品貸出管理アプリ

社内備品の貸出・返却を記録するアプリを題材に、概念設計 → 論理設計 → 物理設計の3段階を実際に踏んで見せるケーススタディ。詳細は `docs/備品貸出管理アプリ_データモデリング.md` を参照。
